# Dynamic Notch

Windows 10/11 x64 için medya kontrolleri, takvim, hava durumu, pano geçmişi ve indirmeler sunan taşınabilir bir masaüstü uygulaması.

1. GitHub Releases bölümünden `DynamicNotch-win-x64.zip` dosyasını indir ve yazılabilir bir klasöre çıkart.
2. `Dynamic Notch.exe` dosyasını aç. Uygulama sistem tepsisinde çalışır.
3. Canlı tarayıcı indirmeleri isteğe bağlıdır. **İndirmeler → Tarayıcıyı bağla** yoluyla paketteki uzantıyı Chrome veya Edge'e yükleyebilirsin.

**Ayarlar → Uygulamayı güncelle** bölümünden sürümü elle kontrol edebilirsin. Uygulama açılışta da GitHub Releases'i kontrol eder ve yüklemeden önce onay ister. GitHub'da yalnızca yayımlanmış sayısal `vMAJOR.MINOR.PATCH` sürümleri güncelleme olarak sunulur.
